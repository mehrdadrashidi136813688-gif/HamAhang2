هماهنگ — پروژه آماده ساخت APK (نسخه آزمایشی رابط Stage 2)

این بسته، رابط مرحله دوم هماهنگ را در قالب Android WebView قرار داده و برای ساخت APK از GitHub Actions آماده شده است. این نسخه دمو است؛ اطلاعات داخل برنامه فقط روی همین گوشی ذخیره می‌شود. ورود پیامکی واقعی، سرور و همگام‌سازی بین گوشی‌ها هنوز فعال نیست.

ساخت APK بدون Android Studio:
1) این ZIP را استخراج کنید.
2) در GitHub یک repository جدید بسازید.
3) تمام محتویات همین پوشه (از جمله پوشه .github) را به repository آپلود کنید.
4) وارد تب Actions شوید و workflow با عنوان Build Android APK را انتخاب کنید.
5) روی Run workflow بزنید (اگر درخواست کرد، شاخه main را انتخاب کنید).
6) پس از اتمام موفق build، در صفحه اجرای workflow پایین بخش Artifacts فایل hamahang-apk را دانلود کنید.
7) ZIP دانلودشده را باز کنید؛ فایل app-debug.apk را روی گوشی نصب کنید. ممکن است لازم باشد برای برنامه فایل‌ها/مرورگر اجازه Install unknown apps فعال شود.

توجه: این بسته خودش APK آماده نیست؛ GitHub Actions آن را روی سرورهایش می‌سازد. اگر GitHub در دسترس نباشد، فعلاً ساخت مستقیم APK در این محیط ممکن نیست.
