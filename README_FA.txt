هماهنگ — آپدیت v1.3 با پوسته لوکس بنفش و طلایی (تیره)

این نسخه، به‌روزرسانی کامل نسخه قبلی (v1.2 / versionCode 3) است:
- پوسته جدید لوکس تیره + طلایی
- اسپلش تمام‌صفحه splash-luxury.png
- آیکون طلایی جدید
- صفحه اسکن (نمایشی)
- ناوبری ۶ دکمه‌ای: خانه / خدمات / اسکن / کیف پول / همکاران / حساب (مراسم من از داخل حساب)
- حفظ همه امکانات قبلی: دسته‌ها، ارائه‌دهندگان، کیف پول آزمایشی، پنل همکاران، پروفایل، برنامه‌ریز مراسم، پنل مدیر
- applicationId بدون تغییر: com.hamahang.app
- versionCode 4 / versionName 1.3 — برای اینکه گوشی آن را آپدیت تشخیص دهد

شرط مهم آپدیت:
حتماً با همان کی‌استور قبلی (HAMAHANG_KEYSTORE_BASE64 + KEYSTORE_PASSWORD) امضا شود.
اگر با کلید جدید امضا شود، گوشی آن را برنامه جدید می‌بیند و روی نسخه قبلی نصب نمی‌شود.

نصب روی همان ریپوی قبلی GitHub (توصیه‌شده برای آپدیت):
1) محتویات این پوشه را جایگزین فایل‌های ریپوی قبلی در شاخه main کنید (پوشه .github حتماً باشد).
2) تب Actions > workflow با نام Build Hamahang Signed APK > Run workflow (شاخه main).
3) بعد از سبز شدن build، از پایین صفحه Artifact با نام hamahang-release-apk-v1.3 را دانلود کنید.
4) فایل app-release.apk داخل ZIP را روی گوشی که نسخه قبلی روی آن نصب است نصب کنید — باید به‌عنوان Update شناخته شود.
5) اگر خطای App not installed / signatures do not match گرفتید یعنی کلید امضا عوض شده است.

ساخت ریپوی جدید فقط برای تست تمیز خوب است، برای انتشار آپدیت واقعی همان ریپوی قبلی را به‌روز کنید.
